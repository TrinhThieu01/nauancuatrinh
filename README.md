# PantryChef 2.9 — Hero dashboard refresh

This package builds on PantryChef 2.8 (camera/gallery image selection) and refreshes the top hero section to feel more useful and less empty:
- clearer brand/kicker and headline hierarchy
- concise benefits row
- compact kitchen-tip card with an action that filters pantry items nearing expiry
- responsive layout for desktop, tablet, and mobile

## Run
- Node.js 20+
- `npm install`
- configure `DATABASE_URL` for the PostgreSQL service
- `npm start`

This package has not been deployed to VibeHost or integration-tested against a live PostgreSQL instance. Keep your current database and back up the repository before replacing files.
